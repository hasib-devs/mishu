# Chithi Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build phase 1 of Chithi: D1-backed CRUD API on Hono with Drizzle + Zod, and a `/chithi` dashboard with a shadcn modal form.

**Architecture:** Mount a Hono app inside the existing Worker for `/api/chithis*` only; leave the chat streaming handler and NVIDIA proxy untouched. All worker-side modules live under `worker/chithi/` because `tsconfig.worker.json` includes only `worker/`. The service layer owns DB rules so the future hourly cron can reuse it without a schema change.

**Tech Stack:** Cloudflare Worker + D1, Hono, `@hono/zod-validator`, Zod 4 (already installed), Drizzle ORM + drizzle-kit, React 19 + Vite 8, shadcn/base-ui, `node:test`.

**Spec:** `docs/superpowers/specs/2026-11-25-chithi-design.md`

## Global Constraints

- Repo root: `/Users/hasib/Documents/Exp/mishu`; branch `develop`; run all commands from there.
- Node v26.7.0, TypeScript 6, pnpm. Tests: `node --test tests/*.test.ts` (Node strips TS types).
- `tsconfig.worker.json` includes only `worker/`; `tsconfig.app.json` includes only `src/`. Put worker-side modules under `worker/`, client modules under `src/`.
- Existing D1 binding is `DB`; database name `mishu-threads`; applied migrations are `0001_init.sql`, `0002_message_parts.sql`. New migration is `migrations/0003_chithi.sql`; apply locally only via Wrangler.
- `pnpm run lint` has pre-existing errors; this work adds none. `pnpm run build` must pass.
- Content rule: 1–600 characters after trim. `source` is `manual` or `ai`; default `paper_style` is `"classic"`.
- HTTP clients may send only `content` (POST/PATCH) and `limit` (GET list). `generated_for` and `source` are service-layer inputs only.
- Never print or commit secret values. Do not commit anything beyond the task's own files; no pushes.

## Review Focus

- Bengali text at the boundary: a 600-character Bengali letter is accepted and a 601-character one is rejected — pinned in Task 2, Step 1.
- Whitespace-only content: `"   "` is rejected with 400, not stored as a blank letter — pinned in Task 2, Step 1.
- Duplicate hour slot: two service calls with the same hour-aligned `generatedFor` throw `SlotTakenError` — pinned in Task 2, Step 1.
- Unauthenticated caller sends `source: "ai"` and `generatedFor: <hour>` to the HTTP API: fields are ignored, row stays `manual` with null slot — pinned in Task 3, Step 1.
- Unknown id and unknown `/api/chithis/...` subpath: JSON 404, never forwarded to the NVIDIA proxy — pinned in Task 3, Step 1.
